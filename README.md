# toca-rouge-site

Source for **tocarougeevents.com** — the Toca Rouge audience capture funnel.
Deployed via GitHub Pages from this repo.

| File | Purpose |
|---|---|
| `index.html` | Landing page |
| `signup.html` | Signup form — POSTs directly to the linked Google Sheet via the Form's own `entry.*` fields. Reads `?src=` for attribution. |
| `privacy.html` | Privacy notice (real page, not a Doc link) |
| `CNAME` | Maps the custom domain. **Do not delete** — removing it breaks `tocarougeevents.com`. |

## Identity — v1, shipped as interim (2026-08-15)

The site now carries the **v1 Toca Rouge identity**: Bebas Neue wordmark,
accent `#E4002B`, `TOCA` in the foreground colour and `ROUGE` in the accent.

v1 was built on 2026-08-11 and **rejected the same day as a final identity** —
generic Google Font, a picked-not-derived colour, no real design process. It is
shipped here deliberately as an **interim** look, because the alternative was
the pre-brand placeholder (`#d31027`, system font) with an event 28 days out.

The real identity is the 8-phase Brand Identity Workflow in Paul's vault,
paused at Phase 2. When it lands, it replaces this.
